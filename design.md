# Wool Sneaker E-commerce Design Style Guide

## Design Philosophy
**"Natural Wool Meets Urban Tech"** - A sophisticated fusion of organic warmth and contemporary minimalism that embodies the premium nature of merino wool footwear.

## Color Palette
**Primary Colors:**
- Warm White (#FEFCF8) - Main background, representing pure wool
- Oat (#F5F1E8) - Secondary backgrounds and subtle sections
- Mist Grey (#E8E2D5) - Borders, dividers, and muted elements

**Accent Colors:**
- Sage (#A8A090) - Text and subtle interactive elements
- Charcoal (#2C2B28) - Primary text and strong contrast elements
- Soft Cream (#F9F6F0) - Card backgrounds and elevated surfaces

**Gradient Combinations:**
- Hero Background: Warm White to Oat (linear, 135deg)
- Card Hover: Oat to Mist Grey (linear, 45deg)
- Button States: Sage to Charcoal (linear, 90deg)

## Typography
**Primary Font:** "Tiempos Text" - Elegant serif for headings and brand elements
**Secondary Font:** "Suisse Int'l" - Clean sans-serif for body text and UI elements
**Accent Font:** "Canela Text" - Sophisticated serif for special emphasis

**Hierarchy:**
- H1: 3.5rem, Tiempos Text, Charcoal
- H2: 2.5rem, Tiempos Text, Sage
- H3: 1.75rem, Suisse Int'l Medium, Charcoal
- Body: 1rem, Suisse Int'l Regular, Sage
- Caption: 0.875rem, Suisse Int'l Regular, Mist Grey

## Visual Language
**Aesthetic Principles:**
- Minimalist luxury with organic warmth
- Soft, tactile visual elements that evoke wool texture
- Clean geometric forms balanced with natural curves
- Subtle sophistication without ostentation

**Material Design:**
- Soft shadows with warm undertones
- Rounded corners (8px radius) for organic feel
- Subtle texture overlays suggesting wool fiber
- Layered depth with gentle elevation

## Visual Effects & Animation
**Used Libraries:**
- Anime.js for smooth micro-interactions
- Shader-park for wool texture backgrounds
- ECharts.js for data visualization
- Splide.js for product carousels
- p5.js for creative coding elements

**Effect Types:**
- Gentle fade-in animations on scroll
- Soft hover states with wool-like texture reveal
- Breathing animation for hero elements
- Particle systems suggesting wool fibers
- Smooth color transitions between states

**Header Effect:**
- Animated wool texture background using shader-park
- Subtle parallax scrolling with depth layers
- Color-shifting text with warm undertones
- Floating particle system representing wool fibers

**Interactive Elements:**
- Soft glow effects on hover
- Gentle scale transformations (1.02x)
- Color morphing from Sage to Charcoal
- Shadow expansion with warm lighting
- Smooth state transitions (300ms ease-out)

## Layout & Composition
**Grid System:**
- 12-column responsive grid
- Generous whitespace (minimum 2rem gutters)
- Organic asymmetrical layouts
- Content-first hierarchy

**Spacing Scale:**
- XS: 0.5rem (8px)
- S: 1rem (16px)
- M: 2rem (32px)
- L: 3rem (48px)
- XL: 4rem (64px)

**Visual Rhythm:**
- Consistent vertical rhythm (1.5rem baseline)
- Golden ratio proportions for major elements
- Organic spacing that breathes naturally
- Balanced composition with focal points

## Imagery Style
**Photography Direction:**
- Soft, natural lighting with warm undertones
- Lifestyle shots in minimalist urban environments
- Close-up texture shots highlighting wool fiber detail
- Neutral backgrounds with subtle organic elements

**Product Photography:**
- Clean white backgrounds with soft shadows
- Multiple angles showing wool texture
- Lifestyle context shots with urban settings
- Detail shots emphasizing craftsmanship

**Graphic Elements:**
- Subtle geometric patterns inspired by wool weave
